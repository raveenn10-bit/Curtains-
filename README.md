# Madu Curtains — Custom Curtains & Home Interior Decor (Galle, Sri Lanka)

Developed by **Harsh Apex Digital Solutions**.

## Tech Stack
- Next.js 15 (App Router) + TypeScript
- Tailwind CSS
- GSAP + Motion (`motion/react`)
- Lucide Icons (`lucide-react`)
- Next.js Image Optimization (`avif` / `webp`)

## Local Development & Vercel Deployment
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Run typecheck, lint, and production build:
   ```bash
   npm run typecheck && npm run lint && npm run build
   ```
4. Deploy directly to Vercel (`vercel --prod` or connect the repository in Vercel Dashboard).
